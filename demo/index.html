Model and evaluation notes

The original scikit-learn 1.6.1 model's coefficients, intercept, StandardScaler parameters and feature order are embedded here. The same one-hot encoding, scaling and logistic function are applied in JavaScript. No retraining is performed.

The notebook reports ROC-AUC ≈ 0.842; at threshold 0.3, churn precision ≈ 0.52 and recall ≈ 0.75. These are exploratory results: scaling was fitted before cross-validation, and the threshold was selected using test-set results. A separate validation and untouched test set are needed for a reliable final evaluation. Probabilities have not been separately calibrated.

Service options are kept consistent: customers without phone service use “No phone service” for multiple lines; customers without internet use “No internet service” for internet add-ons.
